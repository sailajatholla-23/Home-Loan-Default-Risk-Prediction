# Home Loan Default Risk Prediction Using Machine Learning

## Project Overview

This project focuses on analyzing financial and credit history data to understand loan repayment patterns and predict loan default risk using machine learning techniques. It involves data preprocessing, exploratory data analysis, feature engineering, model building, and performance evaluation.

## Problem Statement

Financial institutions need to assess the risk associated with lending money to applicants. Analyzing financial records and previous repayment information can help identify patterns associated with loan default. This project explores machine learning approaches to analyze applicant-related data and predict loan default risk.

## Project Objectives

* Analyze financial and credit history data.
* Perform exploratory data analysis to identify important patterns.
* Handle missing values and prepare datasets for modeling.
* Perform feature engineering to extract useful information.
* Train and evaluate machine learning models.
* Compare model performance using appropriate evaluation metrics.

## Dataset Information

The project uses multiple related datasets containing financial and credit history information.

The dataset files include information related to:

* Previous credit records.
* Credit balance history.
* Loan installment payments.
* Financial and repayment-related patterns.

The project works with seven dataset files as specified in the project materials.
